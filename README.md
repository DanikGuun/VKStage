Тестовое на стажировку в ВК. 
Задачей было сделать приложение, состоящее из мини-приложений. 
Оно, в целом работает, но с некоторыми недостатками в реализации. 
В плане архитектуры считаю достатком хорошую иерархию мини-приложений и их взаимодействие через протоколы. 
Из недостатков хочу отметить, хранение размера (мальенькое, полэкрана, полный экран) в классе приложениa. 
По хорошему стоило вообще не затрагивать размер в классе мини-приложения, а делать это только в самих ячейках. 
Также из плюсов хочу отметить самописную графику для крестиков-ноликов и таймера через CD+CA и адаптивность под айпады.
